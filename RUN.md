# Как запустить проект Rodina Moskva

## 1. Установить Node.js (если ещё не установлен)

1. Открой в браузере: **https://nodejs.org/ru**
2. Скачай версию **LTS** (зелёная кнопка «Рекомендуется большинству пользователей»).
3. Запусти скачанный установщик (`.msi`).
4. Пройди шаги установки (можно оставить все по умолчанию). Важно: отметь пункт **«Add to PATH»**, если он есть.
5. В конце нажми **Finish**. Если установщик предложил перезапустить терминал — закрой все окна терминала/CMD/PowerShell и открой новое.

**Проверка:** открой новый терминал (PowerShell или CMD) и введи:
```text
node --version
npm --version
```
Должны появиться номера версий (например `v20.x.x` и `10.x.x`). Если команды не найдены — перезагрузи ПК и проверь снова.

---

## 2. Запустить бэкенд (API регистрации)

В терминале выполни по очереди:

```text
cd c:\Projects\server
npm install
npm start
```

После `npm start` должно появиться сообщение вроде: **Rodina API: http://localhost:3001**.  
Окно терминала не закрывай — пока оно открыто, сервер работает.

---

## 3. Открыть сайт

**Вариант А — просто открыть файл:**  
Дважды кликни по `c:\Projects\rodina-moskva.html` или перетащи файл в окно браузера. Форма «Записаться» будет отправлять заявки на бэкенд (порт 3001).

**Вариант Б — через Live Server в VS Code/Cursor:**  
Если установлено расширение Live Server: правый клик по `rodina-moskva.html` → «Open with Live Server». Сайт откроется по адресу `http://127.0.0.1:5500` (или похожему).

---

## Итого: что должно быть запущено

| Что              | Как запустить                          |
|------------------|----------------------------------------|
| Бэкенд (API)     | Терминал: `cd c:\Projects\server` → `npm start` |
| Сайт             | Открыть `rodina-moskva.html` в браузере или через Live Server |

Сначала запусти бэкенд, потом открой страницу. Нажми «Записаться» у матча, заполни форму — заявка сохранится в базу.
